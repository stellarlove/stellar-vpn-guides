# 回国后哪些网站和 App 需要 VPN：2026 清单

**结论：凡是账号体系在 Google、Meta、OpenAI、Anthropic 这些公司的服务，回国后基本都需要海外线路；国内公司的服务和大部分静态网站不需要。** 下面按你日常会碰到的类别列出来，方便回国前判断哪些要提前准备。

## 需要 Stellar 的

| 类别 | 服务 |
| --- | --- |
| 搜索与邮箱 | Google 搜索、Gmail、Google Drive / Docs / Photos、Google Maps、Google Scholar |
| 视频与音乐 | YouTube、Netflix、Disney+、Spotify、Twitch |
| 社交 | Instagram、Facebook、Threads、X、Reddit、Discord、Telegram、WhatsApp、Signal |
| AI 工具 | ChatGPT、Claude、Gemini、Perplexity、Midjourney、Claude Code、Codex CLI |
| 工作协作 | Slack、Notion、Figma、Dropbox、部分 Zoom 场景 |
| 开发 | GitHub（时通时断）、npm / PyPI 官方源、Docker Hub、Hugging Face |
| 学术 | 多数海外期刊库、arXiv 偶尔慢、大学 VPN 门户 |
| 新闻 | 多数海外媒体 |

## 不需要的

- 微信、支付宝、淘宝、京东、美团、滴滴、12306、各家银行 App
- 国内视频和音乐：B 站、爱奇艺、网易云、QQ 音乐
- 大部分海外品牌的中国站（Apple、Microsoft 官网中国区）
- iCloud 中国区、国内 App Store

## 处在中间的

- **Apple 服务**：海外 Apple ID 的 App Store 通常能打开，但下载慢；iMessage 和 FaceTime 可用。
- **Microsoft**：Outlook.com、OneDrive、Teams 时快时慢，装 Stellar 后稳定。
- **Steam**：商店页面慢，下载走 CDN 一般正常。
- **Zoom / Google Meet**：Zoom 国际会议可能需要线路，Google Meet 需要。

## 怎么用最省事

在 Stellar 里保持**智能模式**：上表第一类自动走海外线路，第二类直连，不用来回切换。遇到某个网站判断地区异常，临时切**全局模式**即可。两种模式的区别见 [模式说明](https://stellar.dog/zh/docs/modes)。

回国前把客户端装好、登录一次，落地后打开就能用。完整准备清单见 [回国前的网络准备](https://stellar.dog/zh/docs/returning-to-china)。
